# DotaLens

DotaLens 是一个本地自用的 Dota 2 职业选手资料与参赛履历查询工具。

项目当前处于立项阶段。产品范围、数据方案、系统设计与实施计划见：

- [项目开发规则](AGENTS.md)
- [项目立项书](docs/project-proposal.md)
- [数据模型](docs/data-model.md)
- [开发路线图](docs/roadmap.md)

## 当前结论

- MVP 聚焦选手个人资料、所属战队、参赛履历、赛事名次与奖金。
- Liquipedia 数据通过其官方 API 获取；不自动抓取普通 HTML 页面。
- 使用 SQLite 本地存储，单个应用同时完成同步和查询，不引入独立服务。
- 外部数据保留来源链接和同步时间，方便核对与更新。
- KDA、英雄池、GPM/XPM 等比赛级数据不属于首期 Liquipedia 采集范围，后续接入 OpenDota 或 STRATZ。

## 本地启动

```bash
cp .env.example .env
npm install
npx prisma db push
npm run db:seed
npm run dev
```

打开 <http://localhost:3000> 后，在首页输入选手 ID 即可同步；大小写、空格、连字符和常见特殊字符差异会自动适配，无法唯一匹配时会提示输入更完整的 ID。项目已提供本地自用 User-Agent；如需对外使用，请在 `.env` 中换成真实项目地址和联系邮箱。

当前同步支持昵称、实名、曾用 ID、国籍、出生日期、状态、位置、当前与历史战队，以及赛事日期、等级、名次、代表队伍、赛果和奖金。

选手详情支持按赛事级别筛选，并显示 Liquipedia 信息框中的个人 `Total Winnings` 和各级别冠军数。赛事列表中的单项奖金仍采用 Results 表格原始值。

详情分为两个页面：参赛履历展示 `/Results` 的完整赛事记录，主要成就展示选手主页 `Achievements` 中的精选成绩。
每个选手详情页都可以单独重新同步该选手，完成后自动刷新其个人资料、战队和赛事数据。
首页输入选手 ID 后，同步期间会显示加载动画和等待提示，并在完成或失败后给出结果。

首页支持按选手位置、国籍和历史效力俱乐部组合筛选；俱乐部筛选包含当前及过去效力记录。
选手列表按游戏 ID 的字母顺序排列，不区分大小写。
选手卡片可以从首页隐藏；该操作只设置 SQLite 中的隐藏标记，不删除选手及其历史数据。再次同步该选手时会自动取消隐藏。

动态页面从 SQLite 读取，因此页面跳转不会等待 Liquipedia。点击“同步动态”时才获取当前季度人员调整，以及已同步俱乐部、版本、英雄和物品页面的近期更新。Wiki 页面更新不等同于俱乐部或 Valve 官方公告，页面会保留 Liquipedia 与外部来源链接。
人员调整会保留 Active、Inactive、Coach、Analyst、Manager、Stand-in 等前后身份；同一俱乐部内的身份切换会显示独立标签，避免被误认为无变化。

俱乐部页面只列出仍在运营的俱乐部。选手同步时会登记其当前俱乐部；进入俱乐部详情后可以手动从 Liquipedia 更新地区、成立时间、赞助商和当前人员，已解散或标记 inactive 的俱乐部会从列表隐藏。
